# 마음방 웹앱 기획서 v4.1

> v4에서 고친 것: 감정 낱말 개수 44 → **43개** (포스터 1의 35개 + 포스터 2에서 추가 8개). 그림 에셋 완성(`에셋/`).

## 1. 한눈에 보기
- **앱 이름**: **마음방**
- **무엇을**: 교사가 '방'을 만들면 학생들이 QR이나 숫자 코드로 들어와 얼굴·색·모양·그림으로 감정을 표현하고, 결과물이 방의 **감정 갤러리**에 모이는 웹앱. 교사는 같은 활동을 **활동지로 인쇄**할 수 있음
- **누구와**: 특수교육대상 초등 학생. 회원가입 없이 바로 씀
- **어디서**: 교사는 전자칠판(갤러리 띄우기)과 PC(방 편집·인쇄), 학생은 태블릿이나 전자칠판
- **핵심 생각**: 하나의 표현 = 하나의 정답 감정이 아님. 표현하고 → 이름 붙이고 → 크기 나타내고 → 서로 보며 이야기 나누기

## 1-1. 컨셉과 방 이름
**마음방 = 감정들이 사는 집.** 선생님이 우리 반 마음방을 만들고, 그 안에 활동마다 방이 있음. 첫 화면은 집 그림, 방마다 문으로 들어감.

| 기능 | 이름 |
|---|---|
| 교사가 만드는 방 | 우리 반 마음방 |
| 얼굴로 / 색으로 / 모양으로 / 그림으로 | **표정방 / 색깔방 / 모양방 / 그림방** |
| 갤러리 | **전시방** |
| 혼자 하기 | **나의방** |
| 감정 기록 대시보드 / 활동지 인쇄 / 교사 설정 | **기록방 / 인쇄방 / 열쇠방** (선생님만 열쇠로 들어감) |
| 감정 이름 붙이기 + 크기 | 이름표 붙이기 (모든 방 끝에 나오는 단계) |

디자인: 에셋 그림과 같은 스티커 일러스트 스타일 — 갈색 테두리, 평면 색, 아래로 밀린 단색 그림자, 통통 튀는 움직임 (자세한 것은 CLAUDE.md)

## 2. 전체 흐름
```
첫 화면 (마음방)
 ├─ [선생님] 방 만들기 ─→ 교사 모드
 │      ├ 방 편집(학생 명단·감정·부품·활동)
 │      ├ 갤러리 띄우기(QR·코드 표시)
 │      ├ 감정 기록 대시보드
 │      └ 활동지 인쇄
 │      (만든 방은 쿠키에 저장 → "내 방 목록")
 ├─ [학생] 방 들어가기 (QR / 숫자 6자리)
 │      └ 내 이름 고르기 → 표현 활동 → 만들기 → 감정 이름 붙이기(+크기) → 갤러리에 올리기
 └─ [혼자 하기] 방 없이 바로 만들기 → 이미지 저장만
```
- 좌측 상단: 전체화면 / 우측 상단: 교사 모드(설정)
- 하단: `© 2026 특수교사 은티 · @special_eun_t` (인스타 주소는 첫 화면에서만 클릭)

## 3. 방 시스템
### 교사
- **방 만들기**: 방 이름 입력 → 6자리 숫자 코드와 QR 자동 생성
- **쿠키 저장**: 방 소유 정보(방 ID + 교사 열쇠)를 쿠키/로컬 저장소에 보관 → 로그인 없이 내 방 편집
- **방 관리 PIN(백업)**: 방 만들 때 4자리 PIN 설정 → 쿠키가 지워지거나 다른 기기에서 열 때 "방 코드 + PIN"으로 교사 권한 되찾기
- **방 보관**: **선생님이 지울 때까지** (자동 삭제 없음). 방 지우기는 PIN 한 번 더 확인
- **방 복제**: 방 설정(명단·감정·활동)을 복사해 다른 수업에 사용
- 방 열기/닫기: 닫힌 방은 학생 입장 불가, 갤러리 보기만

### 학생 명단 (교사 설정)
- **CSV 파일로 한 번에 입력**: 한 줄에 이름 하나 (예시 파일 내려받기 제공)
- 붙여넣기 입력: 엑셀/한글에서 이름 열 복사 → 줄마다 한 명
- 한 명씩 추가·수정·삭제, 순서 바꾸기
- 학생마다 사진이나 그림(선택) → 이름 버튼에 같이 보여 글을 못 읽는 학생도 자기 버튼을 찾음

### 학생 입장
- QR 찍으면 바로 입장, 또는 숫자 코드 입력(큰 숫자 키패드)
- **선생님이 입력한 명단에서 내 이름 버튼 고르기** (직접 입력 없음)
- 로그인·비밀번호 없음

## 5. 공통: 감정 이름 붙이기 (+ 감정 크기)
모든 활동 끝에 같은 순서로 진행
1. **큰 감정 고르기**: 7가지 색 카드 (기쁨·놀람·분노·불편함·슬픔·두려움·무기력함) — 대표 그림 `group_*.png`
2. **감정 크기 고르기 (드래그 수직선)**
   ```
    답답해요  불만스러워요  짜증나요  신경질 나요  화나요
     (그림)     (그림)      (그림)     (그림)      (그림)   ← 낱말 그림 anger_1~5
   ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●
   연한 색 ──────────────────────────────────▶ 진한 색
               ◀ 손잡이를 끌어서 고르기 ▶
   ```
   - 고른 큰 감정의 낱말 5개가 **작은 감정 → 큰 감정** 순으로 수직선 위에 놓임
   - 손잡이를 끌면 가까운 낱말에 착 붙고, 그 낱말과 크기(1~5)가 함께 선택됨
   - 선이 오른쪽으로 갈수록 색이 진해짐, 낱말 읽어 주기
   - 포스터 2에서 온 낱말(신나요·감사해요 등)은 교사가 수직선 위치(1~5)를 정해 둠 → 같은 위치에 낱말이 여럿이면 그 칸에서 한 번 더 고르기
   - 끌기가 어려운 학생은 낱말을 바로 탭해도 됨
3. *(선택)* **왜 그럴까?**: "○○해서 △△해요" 문장 만들기 — 직접 쓰기 또는 넘어가기
- 교사 설정: 1단계만 / 1~2단계 / 전체 (학생 수준별)
- 갤러리 카드와 기록에 **낱말 + 크기**가 같이 저장됨 (예: 짜증나요 ■■■□□)

## 7. 감정 갤러리
- 학생이 올리면 **바로** 갤러리에 실시간으로 나타남 (교사 확인 없음)
- 카드: 작품 이미지 + 이름 + 감정 낱말 + 크기 (+ 이유 문장)
- 보기: 전체 / 큰 감정별(색 띠) / 학생별 / 활동별
- 카드 누르면 크게 보기 → 이야기 나누기, 슬라이드쇼
- **교사 관리자 권한**: 작품 삭제(하나씩·여러 개 선택), 학생은 삭제 불가, 삭제 전 확인 창

## 8. 감정 기록 대시보드 (교사)
학생들이 올린 감정 이름·크기 데이터를 모아 보는 화면. 감정 크기는 활동지 없이 여기서만 확인
- **학생별**: 날짜순 감정 기록 (큰 감정 색 + 낱말 + 크기 막대), 작품 썸네일
- **날짜별/수업별**: 그날 반 전체가 고른 감정 한눈에 (큰 감정 색으로 모아보기)
- **흐름 보기**: 한 학생의 감정 크기가 날마다 어떻게 변했는지 꺾은선/막대
- 기간 고르기 (오늘 / 이번 주 / 이번 달 / 전체)
- **인쇄**: 학생별 감정 기록지(한 학생 한 장), 반 전체 요약 한 장 → 상담·관찰 자료로 사용
- CSV 내려받기 (날짜, 학생, 활동, 큰 감정, 낱말, 크기, 이유 문장)

## 9. 활동지 인쇄 (교사)
교사 모드 → [활동지 인쇄] → 활동 고르기 → 종류 고르기 → 옵션 → 미리보기 → 인쇄/PDF 저장

### 공통 옵션
- **감정 낱말 나타내기** (여러 개 선택 가능): 따라쓰기(흐린 글씨) / 빈칸 쓰기 / 낱말 오려 붙이기(오리는 낱말 카드 함께 인쇄)
- 사용할 감정 고르기: 큰 감정 묶음별 또는 낱말 하나하나 체크 (편집한 감정 목록 그대로)
- 학생 이름 칸 넣기 / 명단 이름 미리 찍어서 학생 수만큼 인쇄
- 활동지 하단에 저작권 표시

### 😊 얼굴로 — 한 장에 1개 크게 (수준별 구분 없음, 세 종류가 곧 수준)
| 종류 | 구성 | 옵션 |
|---|---|---|
| **A. 감정 낱말 보고 직접 그리기** | 감정 낱말 + 큰 빈 얼굴 → 표정 직접 그리기 | **예시 얼굴 켜기/끄기** (켜면 옆에 작은 예시 표정) |
| **B. 눈코입 오려 붙이기** | 1쪽: 큰 빈 얼굴 + 낱말 칸 / 2쪽: 오리는 부품(눈썹·눈·코·입) | 부품 종류·개수 고르기 |
| **C. 얼굴-감정 낱말 연결** | 왼쪽 표정 얼굴, 오른쪽 감정 낱말 → 선 잇기 | 문제 수(3~6개) |

### 🎨 색으로 — 한 장 개수 교사 선택(1·2·4), 감정 색 안내 **넣지 않음**(색은 학생 자유)
| 종류 | 구성 |
|---|---|
| **내 마음 색칠하기** | 큰 마음 모양(하트·동그라미 등 선택) + "나는 [ ]해요" → 지금 내 기분 색 칠하기 |
| **감정-색 연결** | 감정 낱말 옆 빈 칸에 어울린다고 생각하는 색 칠하기 (정답 없음) |

### 🔷 모양으로 — 한 장 개수 교사 선택
| 종류 | 구성 |
|---|---|
| **모양 오려 붙여 캐릭터** | 오리는 모양 조각 + 붙이는 칸 → 표정 그려 감정 캐릭터 |
| **내 마음 모양 그리기** | 빈 칸에 내 감정을 모양으로 그리고 색칠 |
| **감정 캐릭터 소개 카드** | 캐릭터 그림 칸 + 이름 + 감정 + "언제 나타나요?" |

### ✏️ 그림으로 — 한 장 개수 교사 선택
| 종류 | 구성 |
|---|---|
| **배경 위에 그리기** | 앱과 같은 빈 얼굴·빈 마음 모양 배경(선택) 위에 자유롭게 그리기 + 감정 낱말 |

### 🏷️ 감정 낱말 — 한 장 개수 교사 선택
낱말 자체를 익히는 인쇄물 (표현 활동 전 미리 배우기·복습용)
| 종류 | 구성 |
|---|---|
| **감정 낱말 카드** | 그림+낱말 카드, 오려서 카드놀이·이야기 나누기. 큰 감정 색 테두리 |
| **감정 묶음 분류하기** | 7가지(또는 고른 묶음) 큰 감정 판 + 오리는 낱말 카드 → 나눠 붙이기 |

### 📏 감정 크기 — 활동지 없음
앱의 드래그 수직선에서만 기록 → 8장 대시보드에서 확인·인쇄

## 10. 이미지 저장·전달
- **학생**: [사진으로 저장] → PNG / 태블릿에서는 [보내기] (공유창)

- '혼자 하기'는 저장·공유만

  - Storage: 작품 이미지, 교사가 올린 부품·낱말·학생 그림
  - Realtime: 갤러리 실시간 갱신
- 교사 권한: 방 만들 때 발급되는 비밀 열쇠(쿠키) + PIN 백업. 학생은 방 코드로 읽기·올리기만
- CSV 읽기: 브라우저에서 처리(UTF-8·EUC-KR 둘 다 지원 — 엑셀 CSV 한글 깨짐 방지)
- 활동지: A4 인쇄용 CSS(@page) + 미리보기, 브라우저 인쇄/PDF 저장. 부품·낱말 그림은 앱과 같은 파일 재사용
- 결과물은 캔버스로 합쳐 PNG 저장, 터치 기준 설계

## 12. 개인정보·운영
- 명단의 이름은 그 방 안에서만 보임, 방 코드를 아는 사람만 입장
- 대시보드·감정 기록은 교사만 볼 수 있음
- 방을 지우면 작품·명단·기록 모두 삭제

## 13. 만드는 순서
1. 방 만들기·PIN·입장(코드/QR)·명단(CSV)·갤러리 뼈대
2. 감정 이름 붙이기 + 드래그 수직선 + 감정 목록 편집
3. 활동: 그림으로 → 색으로 → 얼굴로 → 모양으로
4. 저장·ZIP·갤러리 삭제 관리
5. 대시보드
6. 활동지 인쇄
7. 디자인 다듬기
